To-Do App (todolist-chris)

Une application web implémentant les opérations CRUD de base (Créer, Lire, Mettre à jour, Supprimer) en JavaScript Vanilla. L'état est persistant côté client grâce au localStorage. L'interface intègre une barre de progression dynamique ainsi qu'une animation festive (canvas-confetti) qui se déclenche lorsque toutes les tâches sont accomplies.
